# MetaTwin Clinical Dashboard Mirror

This directory mirrors the latest deployed MetaTwin Clinical dashboard hosted on Hatchable. The dashboard integrates the Railway MetaTwin model through a same-origin proxy and includes patient management, readings, notes, digital-twin visualization, 60-minute forecasts, adverse-event risk, reliability/abstention, Reliability Replay, what-if simulation, alert review, and research evidence.

The hosted application remains the canonical runtime for this dashboard; this mirror keeps the source in the MetaTwin GitHub repository alongside the research/backend implementation.
