# MetaTwin Model Card

## Model purpose

MetaTwin is a research prototype for near-term glucose forecasting and adverse-event risk estimation. It is designed to demonstrate a clinician-facing digital-twin workflow that combines static EHR context with dynamic CGM/wearable/meal signals.

## Primary outputs

1. Glucose endpoint forecast at 60 minutes.
2. Binary adverse-event probability for a glucose excursion above 180 mg/dL or below 70 mg/dL within 60 minutes.
3. Forecast-failure probability and a calibrated Forecast / Caution / Abstain state.
4. Reliability-gated alert candidate.

## Models

- XGBoost regression for glucose forecasting.
- XGBoost classification for the adverse-event layer.
- Patient-grouped OOF XGBoost residual detector for forecast failure.
- Isotonic regression for reliability probability calibration.

## Evaluation

- Temporal holdout rather than random row splitting.
- Persistence baseline.
- MAE and RMSE for glucose forecasting.
- AUROC and AUPRC for failure detection.
- Event precision, recall, F1 and false alarms/day.
- Abstention coverage/error curve.
- Patient-level bootstrap 95% confidence intervals.

## Data

Primary real-data pathway: CGMacros v1.0.0, a publicly accessible PhysioNet dataset with 45 participants, CGM, Fitbit activity/heart rate, meals/macros and baseline health data. The public source is licensed CC BY-NC-SA 4.0. Raw data are not redistributed by this repository.

Development fallback: synthetic data generated by `src/synthetic_data.py`. Synthetic fields and any synthetic EHR extensions are explicitly identified as simulated.

## Limitations

- CGMacros is a small observational dataset and is not a clinical validation cohort for MetaTwin.
- The event definition is a research threshold outcome, not a diagnosis.
- Reliability indicates estimated forecast failure risk; it is not a clinical confidence score.
- What-if scenarios are model perturbations and are not causal estimates or treatment recommendations.
- Population, sensor, preprocessing and temporal-shift differences can limit generalization.
- The prototype does not model medications, insulin dosing or clinician interventions.

## Safety boundary

MetaTwin must not be used to diagnose, prescribe, dose medication, or autonomously make clinical decisions. A displayed event or alert is a research prediction and requires qualified clinical interpretation.
